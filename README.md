# TYCHE

TYCHE is a texas hold 'em poker simulator written in python.  The simulator will model various poker player types based on different player attributes.  The goal of the simulator is to provide a robust framework where these different attributes can be modified and the players will play against one another in various random poker situations.  Monte-carlo style runs will happen to model the different player types.

The players will have the following attributes:
 - Agression (How aggressively the player will play his/her hand)
 - Knowledge (general understanding of the game, situation , stack size play and awarness of other players styles)
 - Inebriation (how inbreated the player is)
 - Analytics (how able the player is to calculated things like pot odds, estimated return etc.)
